# FAQ-бот репетиции (Aviola)

Терминальный чат на Node.js: отвечает на 5 заранее известных вопросов про репетицию хакатона. Совпадение — по ключевым словам (без RAG и нейросетей).

## Как запустить

Нужен [Node.js](https://nodejs.org/) 16+.

```bash
git clone <url-этого-репо>
cd hack-f23e41c4-aviola
npm start
```

Или напрямую:

```bash
node bot.js
```

Автопроверка матчинга:

```bash
npm test
```

В чате: задайте вопрос обычным текстом. `/list` — список FAQ, `/exit` — выход.

## Что получилось

| Файл | Назначение |
|------|------------|
| `faq.txt` | 5 пар вопрос–ответ (время, команда, трек, сдача, призы) |
| `bot.js` | Чат в терминале + поиск ближайшего вопроса по ключевым словам |
| `test.js` | Прогон типовых запросов по пяти темам FAQ |

Логика: токены вопроса пользователя сравниваются с токенами FAQ; при слабом совпадении бот отвечает «не знаю».
